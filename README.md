## Featured project

### [Business Intelligence Assistant](https://github.com/Logesh2097/Business_Intelligence)

A multi-tenant assistant that answers business questions in plain language with a table, a chart and an explanation. Several companies share one installation and never see each other's data.

| | |
|---|---|
| **Question to SQL** | The model writes SQL; a guard checks it; it runs as a read-only database role, in a read-only transaction, under PostgreSQL row-level security |
| **Agents** | A LangGraph supervisor routes each question to Sales, Inventory and Customer agents, each limited to its own tables |
| **Documents (RAG)** | Upload, chunking, embeddings and retrieval with Qdrant, every search filtered by tenant |
| **MCP** | The data tools are served by an MCP server; agents reach data only through them |
| **Web app** | Vue 3, TypeScript, Pinia |
| **Engineering** | FastAPI, Pydantic, `mypy --strict`, a scripted fake model so tests need no API key, and a golden question set checked against the database |

Stack: Python · FastAPI · LangGraph · LangChain · PostgreSQL · MongoDB · Qdrant · Vue 3 · Docker
